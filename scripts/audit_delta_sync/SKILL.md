# Golang Echo Elasticsearch Delta Sync Audit Skill

## Goal
Automate the end-to-end creation of JSON audit configurations from a Golang Echo handler directory (e.g. `delivery/`) and run `audit_delta_sync.py` to audit Delta Sync integrity.

---

## Execution Flow

```
[1. Scan delivery/*_handler.go] -> [2. Breakdown Task (Markdown Checklist)]
                                                |
[5. Final Audit Report] <- [4. Run audit_delta_sync.py & Auto-Fix] <- [3. Write JSON Config Files]
```

---

### Step 1: Scan Handler Files
1. Read all files matching `delivery/*_handler.go` in the specified directory.
2. Extract Echo HTTP routes (`e.POST`, `g.PUT`, `g.PATCH`, `g.DELETE`) and handler functions.
3. Extract request/response Go struct definitions and JSON tags (`json:"field_name"`).

---

### Step 2: Markdown Task Breakdown Checklist
Create a Markdown TODO checklist of configuration files to be generated, organized by domain:

```markdown
### Pending Configuration Tasks
- [ ] `configs/billing/invoices.json` (POST, PUT, PATCH, DELETE)
- [ ] `configs/user/accounts.json` (POST, PUT, PATCH, DELETE)
```

---

### Step 3: Generate JSON Config Files
Create modular JSON files inside `./configs/<domain>/<resource>.json` matching `audit_delta_sync.py` requirements:

```json
[
  {
    "base_path": "/api/v1/billing/invoices",
    "es_index": "billing_invoices",
    "id_field": "invoice_id",
    "steps": [
      {
        "name": "CREATE",
        "method": "POST",
        "path": "/api/v1/billing/invoices",
        "payload": {
          "invoice_id": "INV-2026-001",
          "amount": 150.0,
          "status": "ACTIVE"
        },
        "es_check": {
          "status": "ACTIVE",
          "amount": 150.0
        }
      },
      {
        "name": "UPDATE",
        "method": "PUT",
        "path": "/api/v1/billing/invoices/{id}",
        "payload": {
          "amount": 300.0,
          "status": "ACTIVE"
        },
        "es_check": {
          "amount": 300.0
        }
      },
      {
        "name": "PATCH",
        "method": "PATCH",
        "path": "/api/v1/billing/invoices/{id}",
        "payload": {
          "status": "INACTIVE"
        },
        "es_check": {
          "status": "INACTIVE"
        }
      },
      {
        "name": "DELETE",
        "method": "DELETE",
        "path": "/api/v1/billing/invoices/{id}"
      }
    ]
  }
]
```

---

### Step 4: Run Auditor & Auto-Fix Configs
1. Execute `audit_delta_sync.py`:
   ```bash
   python audit_delta_sync.py --target-url <TARGET_URL> --es-url <ES_URL> --config ./configs
   ```
2. If configuration/payload mismatches occur (404 route, invalid field schema, wrong `id_field`), update the JSON files in `./configs/` and re-run.

---

### Step 5: Final Audit Report
Output the execution report generated by `audit_delta_sync.py`:
- Total APIs Audited
- Pass / Fail Counts & Percentages
- Detailed Failures (Route, ES Index, Monotonicity Violations)
- Teardown Rollback Status
