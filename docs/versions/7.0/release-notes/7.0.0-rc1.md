## Elasticsearch version 7.0.0-rc1

Also see [Breaking changes in 7.0.0-rc1](#breaking-changes-7.0).

### Breaking changes

**Distributed**:
* Remove cluster state size [#40061](https://github.com/elastic/elasticsearch/pull/40061) (issues: [#39806](https://github.com/elastic/elasticsearch/issues/39806), [#39827](https://github.com/elastic/elasticsearch/issues/39827), [#39951](https://github.com/elastic/elasticsearch/issues/39951), [#40016](https://github.com/elastic/elasticsearch/issues/40016))

**Features/Features**:
* Remove Migration Upgrade and Assistance APIs [#40075](https://github.com/elastic/elasticsearch/pull/40075) (issue: [#40014](https://github.com/elastic/elasticsearch/issues/40014))

### Deprecations

**Cluster Coordination**:
* Deprecate size in cluster state response [#39951](https://github.com/elastic/elasticsearch/pull/39951) (issue: [#39806](https://github.com/elastic/elasticsearch/issues/39806))

**Infra/Packaging**:
* Deprecate fallback to java on PATH [#37990](https://github.com/elastic/elasticsearch/pull/37990)

### New features

**Allocation**:
* Node repurpose tool [#39403](https://github.com/elastic/elasticsearch/pull/39403) (issues: [#37347](https://github.com/elastic/elasticsearch/issues/37347), [#37748](https://github.com/elastic/elasticsearch/issues/37748))

**Security**:
* Switch internal security index to ".security-7" [#39337](https://github.com/elastic/elasticsearch/pull/39337) (issue: [#39284](https://github.com/elastic/elasticsearch/issues/39284))
