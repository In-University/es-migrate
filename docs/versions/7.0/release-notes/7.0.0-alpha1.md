## Elasticsearch version 7.0.0-alpha1

The changes listed below have been released for the first time in Elasticsearch 7.0.0-alpha1.

* Remove support for deprecated params._agg/_aggs for scripted metric aggregations [#32979](https://github.com/elastic/elasticsearch/pull/32979) (issues: [#29328](https://github.com/elastic/elasticsearch/issues/29328), [#31597](https://github.com/elastic/elasticsearch/issues/31597))

**Analysis**:
* Remove `delimited_payload_filter` [#27705](https://github.com/elastic/elasticsearch/pull/27705) (issues: [#26625](https://github.com/elastic/elasticsearch/issues/26625), [#27704](https://github.com/elastic/elasticsearch/issues/27704))
