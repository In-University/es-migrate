## Elasticsearch version 8.19.21

Also see [Breaking changes in 8.19](#breaking-changes-8.19).

[float]
### Bug fixes

**ES|QL**:
* Clamp out-of-range `COUNT_DISTINCT` precision thresholds to the maximum [#157553](https://github.com/elastic/elasticsearch/pull/157553) (issue: [#157549](https://github.com/elastic/elasticsearch/issues/157549))
* Fix incorrect results for multi-key `SORT` with `LIMIT` [#155923](https://github.com/elastic/elasticsearch/pull/155923)
* Fix missing columns when `CIDR_MATCH` is used with `CASE` and casts [#156162](https://github.com/elastic/elasticsearch/pull/156162) (issue: [#155979](https://github.com/elastic/elasticsearch/issues/155979))

**Inference**:
* Fix Google Vertex AI `chat_completion` tool calls with non-string arguments [#156665](https://github.com/elastic/elasticsearch/pull/156665) (issue: [#156644](https://github.com/elastic/elasticsearch/issues/156644))

**Infra/Core**:
* Fix error when truncating long JSON in log and error messages [#156382](https://github.com/elastic/elasticsearch/pull/156382) (issue: [#156289](https://github.com/elastic/elasticsearch/issues/156289))

**Infra/Metrics**:
* Fix errors from node flush metrics during shutdown [#157161](https://github.com/elastic/elasticsearch/pull/157161)

**Machine Learning**:
* Re-audit datafeed extraction errors periodically [#157565](https://github.com/elastic/elasticsearch/pull/157565)

**SQL**:
* Reject `ROUND` results that overflow `byte` or `short` values [#157554](https://github.com/elastic/elasticsearch/pull/157554) (issue: [#157550](https://github.com/elastic/elasticsearch/issues/157550))

**Search**:
* Add `search.aggs.max_nested_depth` to limit aggregation nesting [#155743](https://github.com/elastic/elasticsearch/pull/155743)
* Ensure batched queries always return a response [#155908](https://github.com/elastic/elasticsearch/pull/155908)
* Exclude non-metadata `_type` from default search hit fields [#155706](https://github.com/elastic/elasticsearch/pull/155706) (issue: [#110438](https://github.com/elastic/elasticsearch/issues/110438))
* Fix search failures caused by missing query cache shard statistics [#157050](https://github.com/elastic/elasticsearch/pull/157050)
* Keep scroll contexts on transient search queue rejection [#155697](https://github.com/elastic/elasticsearch/pull/155697) (issue: [#90912](https://github.com/elastic/elasticsearch/issues/90912))
* Return a clear error when `search_after` contains a null value [#132434](https://github.com/elastic/elasticsearch/pull/132434) (issue: [#132370](https://github.com/elastic/elasticsearch/issues/132370))
* Return an error for deeply nested aggregations instead of failing the node [#155745](https://github.com/elastic/elasticsearch/pull/155745)

**Snapshot/Restore**:
* Halt the node correctly on fatal errors during S3 multipart uploads [#156765](https://github.com/elastic/elasticsearch/pull/156765)

**Transform**:
* Preserve transform credentials when a deprecated setting is migrated [#156191](https://github.com/elastic/elasticsearch/pull/156191)

**Vector Search**:
* Fix empty `inner_hits` for nested kNN search on quantized vectors [#156332](https://github.com/elastic/elasticsearch/pull/156332) (issue: [#138496](https://github.com/elastic/elasticsearch/issues/138496))
