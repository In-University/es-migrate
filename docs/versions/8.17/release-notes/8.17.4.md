## Elasticsearch version 8.17.4

Also see [Breaking changes in 8.17](#breaking-changes-8.17).

[float]
### Bug fixes

**ES|QL**:
* Catch parsing exception [#124958](https://github.com/elastic/elasticsearch/pull/124958) (issue: [#119025](https://github.com/elastic/elasticsearch/issues/119025))
* Fix early termination in `LuceneSourceOperator` [#123197](https://github.com/elastic/elasticsearch/pull/123197)

**Indices APIs**:
* Avoid hoarding cluster state references during rollover [#124107](https://github.com/elastic/elasticsearch/pull/124107) (issue: [#123893](https://github.com/elastic/elasticsearch/issues/123893))
* [8.17] Avoid hoarding cluster state references during rollover [#124267](https://github.com/elastic/elasticsearch/pull/124267)

**Infra/Core**:
* Prevent rare starvation bug when using scaling `EsThreadPoolExecutor` with empty core pool size. [#124732](https://github.com/elastic/elasticsearch/pull/124732) (issue: [#124667](https://github.com/elastic/elasticsearch/issues/124667))

**Machine Learning**:
* Migrate `model_version` to `model_id` when parsing persistent elser inference endpoints [#124769](https://github.com/elastic/elasticsearch/pull/124769) (issue: [#124675](https://github.com/elastic/elasticsearch/issues/124675))

**Search**:
* Do not let `ShardBulkInferenceActionFilter` unwrap / rewrap ESExceptions [#123890](https://github.com/elastic/elasticsearch/pull/123890)
* Don't generate stacktrace in `TaskCancelledException` [#125002](https://github.com/elastic/elasticsearch/pull/125002)
* Fix concurrency issue in `ScriptSortBuilder` [#123757](https://github.com/elastic/elasticsearch/pull/123757)
* Revert fail-fast disconnect strategy for `_resolve/cluster` [#124241](https://github.com/elastic/elasticsearch/pull/124241)

[float]
### Upgrades

**Security**:
* Bump nimbus-jose-jwt to 10.0.2 [#124544](https://github.com/elastic/elasticsearch/pull/124544)

### Known issues

**{esql}**:

* Some valid queries using an `ENRICH` command can fail when a match field is used that is absent from some indices or shards, either with a 500 status code due to `NullPointerException` or `ClassCastException` or with a 400 status code and `IllegalArgumentException`. This is fixed in [#126187](https://github.com/elastic/elasticsearch/pull/126187).
