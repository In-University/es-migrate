### Bug fixes

**Data streams**:
* Fix wildcard expansion for delete-by-query on data streams [#92891](https://github.com/elastic/elasticsearch/pull/92891)
* Fix wildcard expansion for update-by-query on data streams [#92717](https://github.com/elastic/elasticsearch/pull/92717) (issue: [#90272](https://github.com/elastic/elasticsearch/issues/90272))
* Patch jackson-core with locally modified class #92984
This fixes an issue in jackson parsing (issue: [#92480](https://github.com/elastic/elasticsearch/issues/92480))

**Distributed**:
* Fix `ByteArrayIndexInput` with nonzero offset [#93205](https://github.com/elastic/elasticsearch/pull/93205)

**ILM+SLM**:
* Get repository metadata from the cluster state doesn't throw an exception if a repo is missing [#92914](https://github.com/elastic/elasticsearch/pull/92914)

**Infra/Core**:
* Don't announce ready until file settings are applied [#92856](https://github.com/elastic/elasticsearch/pull/92856) (issue: [#92812](https://github.com/elastic/elasticsearch/issues/92812))

**Machine Learning**:
* Utilise parallel allocations where the inference request contains multiple documents [#92359](https://github.com/elastic/elasticsearch/pull/92359)

**Mapping**:
* Fix `_bulk` api `dynamic_templates` and explicit `op_type` [#92687](https://github.com/elastic/elasticsearch/pull/92687)

**Search**:
* Avoid doing I/O when fetching min and max for keyword fields [#92026](https://github.com/elastic/elasticsearch/pull/92026)
* Reduce memory required for search responses when many shards are unavailable [#91365](https://github.com/elastic/elasticsearch/pull/91365) (issue: [#90622](https://github.com/elastic/elasticsearch/issues/90622))
