## Elasticsearch version 8.8.1

Also see [Breaking changes in 8.8](#breaking-changes-8.8).

[float]
### Bug fixes

**Data streams**:
* Allow the removal of an in-use template if there are other ones matching the dependent data streams [#96286](https://github.com/elastic/elasticsearch/pull/96286)

**Geo**:
* API rest compatibility for type parameter in `geo_bounding_box` query [#96317](https://github.com/elastic/elasticsearch/pull/96317)

**Rollup**:
* Do not copy `index.default_pipeline` and `index.final_pipeline` [#96494](https://github.com/elastic/elasticsearch/pull/96494) (issue: [#96478](https://github.com/elastic/elasticsearch/issues/96478))

**TSDB**:
* Expand start and end time to nanoseconds during coordinator rewrite when needed [#96035](https://github.com/elastic/elasticsearch/pull/96035) (issue: [#96030](https://github.com/elastic/elasticsearch/issues/96030))
* Fix NPE when indexing a document that just has been deleted in a tsdb index [#96461](https://github.com/elastic/elasticsearch/pull/96461)

**Transform**:
* Improve error message on transform `_update` conflict [#96432](https://github.com/elastic/elasticsearch/pull/96432)
* Report version conflict on concurrent updates [#96293](https://github.com/elastic/elasticsearch/pull/96293) (issue: [#96311](https://github.com/elastic/elasticsearch/issues/96311))

[float]
### Enhancements

**Query Languages**:
* Reduce nesting of same bool queries [#96265](https://github.com/elastic/elasticsearch/pull/96265) (issue: [#96236](https://github.com/elastic/elasticsearch/issues/96236))
