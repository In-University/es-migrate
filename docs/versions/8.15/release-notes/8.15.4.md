## Elasticsearch version 8.15.4

Also see [Breaking changes in 8.15](#breaking-changes-8.15).

[float]
### Bug fixes

**Aggregations**:
* Always check the parent breaker with zero bytes in `PreallocatedCircuitBreakerService` [#115181](https://github.com/elastic/elasticsearch/pull/115181)

**ES|QL**:
* ESQL: Disable pushdown of WHERE past STATS [#115308](https://github.com/elastic/elasticsearch/pull/115308) (issue: [#115281](https://github.com/elastic/elasticsearch/issues/115281))

**Geo**:
* Try to simplify geometries that fail with `TopologyException` [#115834](https://github.com/elastic/elasticsearch/pull/115834)

**Infra/Core**:
* Guard blob store local directory creation with `doPrivileged` [#115459](https://github.com/elastic/elasticsearch/pull/115459)

**License**:
* Fix lingering license warning header in IP filter [#115510](https://github.com/elastic/elasticsearch/pull/115510) (issue: [#114865](https://github.com/elastic/elasticsearch/issues/114865))

**Search**:
* Do not exclude empty arrays or empty objects in source filtering [#112250](https://github.com/elastic/elasticsearch/pull/112250) (issue: [#109668](https://github.com/elastic/elasticsearch/issues/109668))
* Fix synthetic source handling for `bit` type in `dense_vector` field [#114407](https://github.com/elastic/elasticsearch/pull/114407) (issue: [#114402](https://github.com/elastic/elasticsearch/issues/114402))

**Vector Search**:
* Fix dim validation for bit `element_type` [#114533](https://github.com/elastic/elasticsearch/pull/114533)
* Support semantic_text in object fields [#114601](https://github.com/elastic/elasticsearch/pull/114601) (issue: [#114401](https://github.com/elastic/elasticsearch/issues/114401))
