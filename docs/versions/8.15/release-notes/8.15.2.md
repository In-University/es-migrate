## Elasticsearch version 8.15.2

Also see [Breaking changes in 8.15](#breaking-changes-8.15).

[float]
### Bug fixes

**Authorization**:
* Fix remote cluster credential secure settings reload [#111535](https://github.com/elastic/elasticsearch/pull/111535)

**ES|QL**:
* ESQL: Don't mutate the `BoolQueryBuilder` in plan [#111519](https://github.com/elastic/elasticsearch/pull/111519)
* ES|QL: Fix `ResolvedEnrichPolicy` serialization (bwc) in v 8.15 [#112985](https://github.com/elastic/elasticsearch/pull/112985) (issue: [#112968](https://github.com/elastic/elasticsearch/issues/112968))
* Fix union-types where one index is missing the field [#111932](https://github.com/elastic/elasticsearch/pull/111932) (issue: [#111912](https://github.com/elastic/elasticsearch/issues/111912))
* Support widening of numeric types in union-types [#112610](https://github.com/elastic/elasticsearch/pull/112610) (issue: [#111277](https://github.com/elastic/elasticsearch/issues/111277))
* Shorten error messages for UnsupportedAttributes [#112819](https://github.com/elastic/elasticsearch/pull/112819)
* Reduce memory footprint of serialized query execution plans [#112865](https://github.com/elastic/elasticsearch/pull/112865)

**Infra/Core**:
* JSON parse failures should be 4xx codes [#112703](https://github.com/elastic/elasticsearch/pull/112703)
* Json parsing exceptions should not cause 500 errors [#111548](https://github.com/elastic/elasticsearch/pull/111548) (issue: [#111542](https://github.com/elastic/elasticsearch/issues/111542))
* Make sure file accesses in `DnRoleMapper` are done in stack frames with permissions [#112400](https://github.com/elastic/elasticsearch/pull/112400)

**Ingest Node**:
* Fix missing header in `put_geoip_database` JSON spec [#112581](https://github.com/elastic/elasticsearch/pull/112581)

**Logs**:
* Fix encoding of dynamic arrays in ignored source [#112713](https://github.com/elastic/elasticsearch/pull/112713)

**Mapping**:
* Full coverage of ECS by ecs@mappings when `date_detection` is disabled [#112444](https://github.com/elastic/elasticsearch/pull/112444) (issue: [#112398](https://github.com/elastic/elasticsearch/issues/112398))

**Search**:
* Fix parsing error in `_terms_enum` API [#112872](https://github.com/elastic/elasticsearch/pull/112872) (issue: [#94378](https://github.com/elastic/elasticsearch/issues/94378))

**Security**:
* Allowlist `tracestate` header on remote server port [#112649](https://github.com/elastic/elasticsearch/pull/112649)

**Vector Search**:
* Fix NPE in `dense_vector` stats [#112720](https://github.com/elastic/elasticsearch/pull/112720)
