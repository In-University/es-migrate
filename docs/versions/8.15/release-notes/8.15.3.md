### Bug fixes

**Aggregations**:
* Don't validate internal stats if they are empty [#113846](https://github.com/elastic/elasticsearch/pull/113846) (issue: [#113811](https://github.com/elastic/elasticsearch/issues/113811))
* Fix `needsScore` computation in `GlobalOrdCardinalityAggregator` [#113129](https://github.com/elastic/elasticsearch/pull/113129) (issue: [#112975](https://github.com/elastic/elasticsearch/issues/112975))

**Authentication**:
* Enables cluster state role mapper, to include ECK operator-defined role mappings in role resolution [#114337](https://github.com/elastic/elasticsearch/pull/114337)

**ES|QL**:
* ES|QL: Ensure minimum capacity for `PlanStreamInput` caches [#114116](https://github.com/elastic/elasticsearch/pull/114116)
* ES|QL: Skip CASE function from `InferIsNotNull` rule checks [#113123](https://github.com/elastic/elasticsearch/pull/113123) (issue: [#112704](https://github.com/elastic/elasticsearch/issues/112704))
* [ESQL] Fix init value in max float aggregation [#113699](https://github.com/elastic/elasticsearch/pull/113699)
* [ESQL] Support datetime data type in Least and Greatest functions [#113961](https://github.com/elastic/elasticsearch/pull/113961)

**Machine Learning**:
* Fix check on E5 model platform compatibility [#113437](https://github.com/elastic/elasticsearch/pull/113437) (issue: [#113577](https://github.com/elastic/elasticsearch/issues/113577))
* Handle parsing ingest processors where definition is not a object [#113697](https://github.com/elastic/elasticsearch/pull/113697) (issue: [#113615](https://github.com/elastic/elasticsearch/issues/113615))
* [ML][backport] Warn for model load failures if they have a status code <500 [#113410](https://github.com/elastic/elasticsearch/pull/113410)
* [M] Fix error message formatting [#113266](https://github.com/elastic/elasticsearch/pull/113266)

**Search**:
* Fix analyzed wildcard query in simple_query_string when disjunctions is empty [#114264](https://github.com/elastic/elasticsearch/pull/114264) (issue: [#114185](https://github.com/elastic/elasticsearch/issues/114185))
* Fix collapse interaction with stored fields [#112761](https://github.com/elastic/elasticsearch/pull/112761) (issue: [#112646](https://github.com/elastic/elasticsearch/issues/112646))
