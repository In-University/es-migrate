### Bug fixes

**Audit**:
* Support removing ignore filters for audit logging [#87675](https://github.com/elastic/elasticsearch/pull/87675) (issue: [#68588](https://github.com/elastic/elasticsearch/issues/68588))

**Ingest**:
* Don't ignore pipeline for upserts in bulk api [#87719](https://github.com/elastic/elasticsearch/pull/87719) (issue: [#87131](https://github.com/elastic/elasticsearch/issues/87131))
* Geoip processor should respect the `ignore_missing` in case of missing database [#87793](https://github.com/elastic/elasticsearch/pull/87793) (issue: [#87345](https://github.com/elastic/elasticsearch/issues/87345))

**Machine Learning**:
* Improve trained model stats API performance [#87978](https://github.com/elastic/elasticsearch/pull/87978)

**Snapshot/Restore**:
* Use the provided SAS token without SDK sanitation that can produce invalid signatures [#88155](https://github.com/elastic/elasticsearch/pull/88155) (issue: [#88140](https://github.com/elastic/elasticsearch/issues/88140))

**Stats**:
* Run `TransportClusterInfoActions` on MANAGEMENT pool [#87679](https://github.com/elastic/elasticsearch/pull/87679)

**Transform**:
* Execute `_refresh` (with system permissions) separately from `delete by query` (with user permissions) [#88005](https://github.com/elastic/elasticsearch/pull/88005) (issue: [#88001](https://github.com/elastic/elasticsearch/issues/88001))
